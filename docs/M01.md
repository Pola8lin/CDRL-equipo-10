# Hito M01: Contrato de Datos de Telemetría

**Objetivo:** 
Definir el contrato de datos de telemetría y preparar la base relacional compatible con cloud.

**Arquitectura y Flujo General:**
Python → Validación → PostgreSQL

**Contrato de Datos y Reglas de Validación:**
* Entidad: `telemetry_reading`
* `device_id`: Obligatorio y no vacío.
* `timestamp`: Formato ISO 8601 / TIMESTAMPTZ.
* `metric`: Únicamente temperature.
* `value`: Rango de -50.00 a 100.00 (incluyendo límites).
* `unit`: Únicamente °C.

**Casos de Prueba:**
* Normal: 23.50 → aceptado
* Límite inferior: -50.00 → aceptado
* Límite superior: 100.00 → aceptado
* Fallo declarado: 150.00 → rechazado

**Ejecución del Proyecto y Pruebas:**
*Nota: Resultados de ejecución pendientes de confirmación.*
* `make setup`
* `make verify`
* `make run`

**Mapa de Archivos:**
* `src/validator.py`: Lógica de validación.
* `tests/test_validator.py`: Casos de prueba automatizados.
* `db/migrations/01_create_table.sql`: Esquema de la base de datos.
* `db/seed/02_insert_data.sql`: Datos sintéticos de prueba.
