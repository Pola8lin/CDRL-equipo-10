# Hito M01: Contrato de Datos de Telemetría

**Objetivo:** Definir el contrato de datos de telemetría y preparar la base relacional compatible con cloud.

**Arquitectura y Flujo General:** Python → Validación → PostgreSQL

**Contrato de Datos y Reglas de Validación:**

* Entidad: `telemetry_reading`
* `device_id`: Obligatorio y no vacío.
* `timestamp`: Formato ISO 8601 / TIMESTAMPTZ.
* `metric`: Únicamente `temperature`.
* `value`: Rango de -50.00 a 100.00 (incluyendo límites).
* `unit`: Únicamente °C.

**Casos de Prueba:**

* Normal: 23.50 → aceptado
* Límite inferior: -50.00 → aceptado
* Límite superior: 100.00 → aceptado
* Fallo declarado: 150.00 → rechazado

**Ejecución del Proyecto y Pruebas:**

El proyecto fue ejecutado correctamente en el entorno local utilizando PostgreSQL y Docker Compose.

* `make setup` → ejecutado correctamente. Aplicó la migración y el seed.
* `make verify` → ejecutado correctamente. Resultado: `8 passed in 0.21s`.
* `make run` → ejecutado correctamente. Levanta los servicios de PostgreSQL y DynamoDB mediante Docker Compose.

Las pruebas automatizadas cubren:

* Caso normal: 23.50 °C → aceptado.
* Límite inferior: -50.00 °C → aceptado.
* Límite superior: 100.00 °C → aceptado.
* Fallo declarado: 150.00 °C → rechazado.
